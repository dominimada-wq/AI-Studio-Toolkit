- Prompts → Inference Transfer (Mission 033) : le sens `Prompts → Envoyer vers Inference`, resté explicitement hors périmètre de Mission 032, est désormais livré. `PromptsPage` gagne un bouton « Envoyer vers Inference », activé/désactivé dynamiquement selon `text_edit.toPlainText().strip()` (mirroir du pattern déjà utilisé par `InferencePage.save_prompt_button`), émettant un signal Qt local `send_to_inference_requested(str)` avec le texte exact actuellement visible — jamais relu depuis le Domain `Prompt`, fonctionnel même sans Prompt actif. Architecture Option A (comparée à une Option B EventBus, écartée : aucune mutation Domain n'a lieu ici, seulement une intention Presentation-layer, hors du contrat `"domaine.verbe"` déjà établi par l'`EventBus`) — `MainWindow` est le seul médiateur, `PromptsPage` ne référence jamais `InferencePage`.
