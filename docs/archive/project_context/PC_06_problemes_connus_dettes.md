**Deux incompatibilités réelles rencontrées et corrigées pendant le smoke réel de Mission 101 — toutes deux des adaptations locales à cette installation OneTrainer, hors code Toolkit, jamais des règles universelles** : le premier run réel a servi de preuve que la chaîne technique Mission 100 fonctionne de bout en bout (`docs/missions/MISSION_101.md`), en révélant au passage deux défauts réels de l'environnement/installation OneTrainer, chacun corrigé après preuve, jamais par anticipation.

1. **GPU/PyTorch — Quadro P4000 (Pascal, sm_61) incompatible avec le build CUDA 13.0 installé.** `train_remote.py` avait réellement lancé, chargé le checkpoint SD1.5 et initialisé CUDA, puis échoué avant tout pas d'entraînement avec `torch.AcceleratorError: CUDA error: no kernel image is available for execution on the device`.
